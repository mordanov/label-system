# 5 Features Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add "show deleted" toggle, search improvements, server-side icons + generation, restore-deleted, and multi-copy printing across Android and Web.

**Architecture:** Backend gains one new endpoint (`/products/{id}/restore`). Android migrates icon loading from bundled assets to HTTP + in-memory cache, adds generate-via-API, and threads five new features through the existing ViewModel/Composable layer. Web adds a Restore button to the deleted-row actions column.

**Tech Stack:** Python/FastAPI (backend), Kotlin/Jetpack Compose (Android), React/JSX (Web)

**Spec:** In-chat design approved 2026-09-26 — see conversation context.

## Global Constraints

- No new Android dependencies (use existing HTTP infrastructure, BitmapFactory, Base64)
- Android icon loading: HTTP GET `/api/icons/{filename}` — filename may contain `/` (e.g. `generated/foo.png`)
- Android generate: POST `/api/icons/generate` with `{"dish_name": name}` — returns `{filename, image_b64}`
- Backend: `GET /api/icons` returns `[{"filename": "..."}]`; auth is Bearer-first, then Basic
- Web i18n: both `en` and `ru` keys required for every new string
- Copies: min 1, max 10; default 1

## Review Focus

- `loadIcon` called for the same filename concurrently (before the first completes): duplicate HTTP requests. **Test:** call `loadIcon("x")` twice before `iconCache` updates; assert single network attempt — added to Task 3.
- `generateIcon` called while already generating: second launch stacks. **Test:** `generatingIcon` blocks second call — added to Task 3.
- Restore of a product that is not deleted: backend must 404. **Test:** added to Task 1.
- `addAndPrint(copies=3)` when print fails on copy 2: state must show Error, not Done. **Test:** covered by existing `doPrint` error path in Task 3.
- Icon list empty on first open of AddProductSheet (network slow): grid shows empty, no crash. LaunchedEffect handles this gracefully by design — no extra test needed.

```python
@router.post("/{product_id}/restore", response_model=ProductResponse)
async def restore_product(
    product_id: uuid.UUID,
    db: AsyncSession = Depends(get_db),
    current_user: str = Depends(get_current_user),
):
    async with db.begin():
        product = await db.get(Product, product_id)
        if not product or not product.is_deleted:
            raise HTTPException(status_code=404, detail="Product not found or not deleted")
        product.is_deleted = False
        product.deleted_at = None
        product.deleted_by = None
    await db.refresh(product)
    return ProductResponse.model_validate(product)
```

```kotlin
fun loadIcon(filename: String) {
    // ponytail: set-based dedup prevents duplicate requests; no retry on failure
    if (_iconRequested.contains(filename)) return
    _iconRequested.add(filename)
    viewModelScope.launch(Dispatchers.IO) {
        try {
            val conn = openApi("/api/icons/$filename", "GET")
            if (conn.responseCode != 200) return@launch
            val bytes = conn.inputStream.readBytes()
            val bmp = BitmapFactory.decodeByteArray(bytes, 0, bytes.size)?.asImageBitmap()
            _iconCache.value = _iconCache.value + (filename to bmp)
        } catch (_: Exception) {}
    }
}
```

- [ ] **Step 2: Add `loadIconList`, `generateIcon`, `clearGeneratedIcon`**

```kotlin
fun loadIconList() = viewModelScope.launch(Dispatchers.IO) {
    try {
        val conn = openApi("/api/icons", "GET")
        if (conn.responseCode != 200) return@launch
        val arr = org.json.JSONArray(conn.inputStream.bufferedReader().readText())
        _iconList.value = (0 until arr.length()).map { arr.getJSONObject(it).getString("filename") }
    } catch (_: Exception) {}
}

fun generateIcon(dishName: String) {
    if (_generatingIcon.value) return  // block concurrent calls
    viewModelScope.launch(Dispatchers.IO) {
        _generatingIcon.value = true
        try {
            val body = org.json.JSONObject().apply { put("dish_name", dishName) }.toString()
            val conn = openApi("/api/icons/generate", "POST", body)
            if (conn.responseCode != 200) return@launch
            val resp = org.json.JSONObject(conn.inputStream.bufferedReader().readText())
            val filename = resp.getString("filename")
            val imageB64 = resp.getString("image_b64")
            val bytes = android.util.Base64.decode(imageB64, android.util.Base64.DEFAULT)
            val bmp = BitmapFactory.decodeByteArray(bytes, 0, bytes.size)?.asImageBitmap()
            _iconRequested.add(filename)  // mark as already loaded
            if (bmp != null) _iconCache.value = _iconCache.value + (filename to bmp)
            // Add to list if not already present
            if (!_iconList.value.contains(filename)) {
                _iconList.value = listOf(filename) + _iconList.value
            }
            _generatedIconFilename.value = filename
        } catch (_: Exception) {
        } finally {
            _generatingIcon.value = false
        }
    }
}

fun clearGeneratedIcon() { _generatedIconFilename.value = null }
```

```kotlin
@Composable
private fun ProductRow(
    product: com.labelapp.data.Product,
    onReprint: (com.labelapp.data.Product) -> Unit,
    onDelete: (String) -> Unit,
    onRestore: (String) -> Unit,
    iconCache: Map<String, androidx.compose.ui.graphics.ImageBitmap?>,
    onLoadIcon: (String) -> Unit,
) {
    LaunchedEffect(product.iconFilename) { onLoadIcon(product.iconFilename) }
    val bitmap = iconCache[product.iconFilename]
    var confirmDelete by remember { mutableStateOf(false) }
    var confirmRestore by remember { mutableStateOf(false) }

    Row(
        modifier = Modifier
            .fillMaxWidth()
            .padding(horizontal = 12.dp, vertical = 8.dp)
            .then(if (product.isDeleted) Modifier.alpha(0.5f) else Modifier),
        verticalAlignment = Alignment.CenterVertically,
    ) {
        if (bitmap != null) {
            Image(bitmap, contentDescription = null, modifier = Modifier.size(40.dp))
        } else {
            Box(Modifier.size(40.dp))
        }
        Spacer(Modifier.width(12.dp))
        Column(Modifier.weight(1f)) {
            Text(
                text = product.name,
                style = MaterialTheme.typography.bodyLarge,
                textDecoration = if (product.isDeleted) TextDecoration.LineThrough else TextDecoration.None,
            )
            Text(
                text = "#${product.inventoryNumber}  ${product.createdAt}",
                style = MaterialTheme.typography.bodySmall,
            )
        }
        if (product.isDeleted) {
            TextButton(onClick = { confirmRestore = true }) { Text("Восст.") }
        } else {
            TextButton(onClick = { onReprint(product) }) { Text("Печать") }
            TextButton(onClick = { confirmDelete = true }) { Text("×") }
        }
    }

    if (confirmDelete) {
        AlertDialog(
            onDismissRequest = { confirmDelete = false },
            confirmButton = {
                TextButton(onClick = { onDelete(product.id); confirmDelete = false }) { Text("Удалить") }
            },
            dismissButton = { TextButton(onClick = { confirmDelete = false }) { Text("Отмена") } },
            title = { Text("Удалить «${product.name}»?") },
        )
    }

    if (confirmRestore) {
        AlertDialog(
            onDismissRequest = { confirmRestore = false },
            confirmButton = {
                TextButton(onClick = { onRestore(product.id); confirmRestore = false }) { Text("Восстановить") }
            },
            dismissButton = { TextButton(onClick = { confirmRestore = false }) { Text("Отмена") } },
            title = { Text("Восстановить «${product.name}»?") },
        )
    }
}
```

```kotlin
            Text("Иконка", style = MaterialTheme.typography.labelMedium)
```
