# UI Migration: shadcn/ui + Tailwind CSS v4

**Date:** 2026-09-18  
**Status:** Approved

## Goal

Migrate the label-system frontend from plain custom CSS to Tailwind CSS v4 + shadcn/ui with a zinc neutral palette and blue accent. The visual direction is Material/shadcn-style: clear component hierarchy, consistent design tokens, accessible primitives.

## Dependencies

Add to `frontend/`:

- `tailwindcss` + `@tailwindcss/vite` — Tailwind v4, Vite-native plugin (no `tailwind.config.js` needed)
- `shadcn/ui` CLI — `npx shadcn@latest init`, zinc theme, CSS variables mode
- shadcn components to install: `button`, `input`, `card`, `label`, `table`, `badge`, `checkbox`
- `lucide-react` — already pulled in by shadcn for icons

No other new dependencies.

## Setup

### `vite.config.js`

Add `@tailwindcss/vite` plugin:

```js
import tailwindcss from '@tailwindcss/vite'
// add to plugins: [tailwindcss(), ...]
```

### `index.css`

Replace entire file with:

```css
@import "tailwindcss";
@import "tw-animate-css"; /* added by shadcn init */
```

Plus shadcn's CSS variable block (generated by `shadcn init`) defining the zinc-based design tokens (`--background`, `--foreground`, `--primary`, `--muted`, `--border`, `--radius`, etc.).

Any canvas-specific styles from `LabelEditor` that cannot be expressed in Tailwind go into a small `label-editor.css` imported only in that component.

## Theme

- **Base neutral:** zinc (cool dark grays)
- **Accent/primary:** blue (maps to shadcn `--primary`, close to current `#2563eb`)
- **Radius:** `0.5rem` (shadcn default `--radius`)
- **Mode:** light only (no dark mode toggle in this migration)

## Component Migration

### `LoginForm.jsx`

Replace `.login-wrap` card with shadcn `Card`, `CardHeader`, `CardContent`. Inputs → shadcn `Input`. Button → shadcn `Button`. Lang switcher stays inline at top-right.

### `App.jsx` (header)

Remove all `.header-actions` CSS classes. Use Tailwind flex utilities directly on the header element. Buttons → shadcn `Button` with `variant="outline"` for secondary actions, default variant for logout.

### `CreateForm.jsx`

Replace `.create-form` with shadcn `Card`. All `input` → `Input` + `Label`. Submit button → `Button`. Qty input stays a native `input` but styled with Tailwind. Icon strip (`.icon-gallery`) stays custom — Tailwind `flex flex-nowrap overflow-x-auto gap-2`.

### `ProductTable.jsx`

Replace `table/th/td` with shadcn `Table`, `TableHeader`, `TableRow`, `TableHead`, `TableBody`, `TableCell`. Status indicators → `Badge` (`variant="outline"` for active, muted for deleted). Row action buttons → `Button size="sm" variant="outline"`, danger variant gets `variant="destructive"`. Pagination stays custom JSX, restyled with Tailwind utilities.

### `SearchBar.jsx`

Replace `.search-bar input` with shadcn `Input`. Suggestions dropdown stays a plain `ul`, restyled with Tailwind (`absolute top-full left-0 z-50 bg-background border rounded-md shadow-md`).

### `ImportPanel.jsx`

File row → Tailwind flex. Checkboxes → shadcn `Checkbox` + `Label`. Name list stays a scrollable `div` with Tailwind. Buttons → `Button`. Import success/warning messages → Tailwind text color utilities.

### `LabelEditor.jsx`

Canvas logic is untouched. Controls (inputs, buttons) migrate to shadcn `Input`, `Button`, `Label`. Layout uses Tailwind grid/flex. Canvas-specific sizing styles go into `label-editor.css`.

### `PrinterStatus.jsx`

Status dot stays a custom `span` (8px circle, Tailwind `w-2 h-2 rounded-full`). Online/offline colors: `bg-green-600` / `bg-red-500`. Text → Tailwind `text-sm text-muted-foreground`.

### `LangSwitcher.jsx`

Pure Tailwind — no shadcn component needed. `flex gap-1 text-sm`, active button gets `text-primary font-semibold`, inactive `text-muted-foreground`.

### `AutocompleteInput.jsx`

Input → shadcn `Input`. Suggestion list stays custom, same Tailwind treatment as `SearchBar` suggestions.

### `IconGallery.jsx` / `IconPickerPanel.jsx`

Pure Tailwind. Selected icon border: `border-2 border-primary bg-primary/10`. Unselected: `border-2 border-border`.

## Modal Backdrop

Replace `.modal-backdrop` / `.modal` CSS with Tailwind:
- Backdrop: `fixed inset-0 bg-black/45 flex items-center justify-center z-50 p-4 overflow-y-auto`
- Modal container: `bg-background rounded-lg p-6 max-w-xl w-full max-h-[calc(100vh-2rem)] overflow-y-auto relative`

The app currently uses plain div modals (not Radix Dialog). This migration keeps that — no behavior change, just restyled. Adopting Radix `Dialog` is a follow-up if focus-trap/accessibility is needed.

## What Does NOT Change

- All component logic, state, API calls — untouched
- Canvas rendering in `LabelEditor`
- `LanguageContext`, `i18n.js`, `api.js` — untouched
- Backend, print-service — untouched
- Responsive breakpoints — replicated with Tailwind `sm:` prefix
